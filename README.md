## 1. โจทย์และโอกาส

คนจำนวนมากรู้สึก "ไม่โอเค" แต่ยังไม่ถึงขั้นที่จะคุยกับผู้เชี่ยวชาญ และไม่รู้ว่าตัวเองรู้สึกอะไรกันแน่ แบบประเมินทางการแพทย์ให้ความรู้สึกหนักและมีภาระผูกพัน โจทย์จึงถามว่าจะมีทางเข้าไปสำรวจใจที่ **เล็ก เป็นกันเอง และได้อะไรกลับไปจริง** ได้อย่างไร

**ผู้ใช้เป้าหมาย (สมมติฐาน ยังไม่ได้ทดสอบกับผู้ใช้จริง):** วัยทำงานที่รู้สึก "ไม่โอเค แต่ไม่ถึงขั้นต้องหาหมอ" และอยากรู้ว่าตัวเองเป็นอย่างไร โดยไม่ต้องสมัครหรือมีภาระผูกพัน

**แรงจูงใจที่ตั้งใจให้เกิด:** ความอยากรู้เล็กๆ ว่า "วันนี้ใจเราเป็นอากาศแบบไหน" ซึ่งตอบง่ายกว่าคำถามว่า "คุณรู้สึกอย่างไร"

## 2. ทางเลือกที่พิจารณา

| ไอเดีย | ข้อดี | ข้อเสีย | ผล |
|---|---|---|---|
| **Mood Weather Check-in** | เข้าใจง่าย ไม่เหมือนแบบประเมิน มาสคอตเมฆกับพระอาทิตย์เข้ากับธีมโดยตรง ทำได้ใน 2 นาที | ต้องระวังไม่ให้ผลลัพธ์ดูเหมือนการวินิจฉัย | **เลือก** |
| Body Scan สั้น | ให้ insight ที่ต่างจากคนอื่น | ต้องระวังภาษามากเพราะเกี่ยวกับร่างกาย เหมาะกับเสียง/การนำพามากกว่าหน้าจอ | ไม่เลือก |
| Energy Battery | วัยทำงานเชื่อมโยงง่าย (burnout) | เสี่ยงคล้ายแบบประเมิน ซึ่งโจทย์บอกว่าไม่ต้องทำ | ไม่เลือก |

**เหตุผลหลักที่เลือก Mood Weather:** ใช้ภาพเปรียบเทียบที่ผู้ใช้เลือกได้ในหนึ่งการแตะ ลดความรู้สึกว่ากำลังถูกประเมิน และมาสคอตของ ooca (เมฆ + พระอาทิตย์) ทำหน้าที่เป็นตัวละครที่ "อยู่ข้างๆ" ได้อย่างเป็นธรรมชาติ

## 3. ประสบการณ์ที่ผู้ใช้ได้รับ

1. **เลือกสภาพอากาศของใจ** (แดดจ้า / เมฆครึ้ม / พายุ / หมอก)
2. **ตอบ 4 คำถามแบบแตะ** รู้สึกอย่างไร · อะไรใช้พลังใจ · อยากให้ตัวเองได้อะไร · อยากวางอะไรลง (ข้ามได้ทุกข้อ ย้อนกลับได้)
3. **ผลลัพธ์ที่ปรับตามคำตอบ** ชื่อสภาวะ (เช่น "หมอกลงในใจ") ประโยคสะท้อนใจ ข้อความกำลังใจ
4. **ก้าวเล็กๆ ถัดไป** 1 อย่างตามที่ผู้ใช้เลือกในข้อ 3
5. **การ์ดที่ระลึก** บันทึกเป็นภาพ หรือแชร์ได้

**ได้อะไรกลับไป:** ชื่อให้ความรู้สึกที่ตอนแรกอาจบอกไม่ถูก, ก้าวเล็กๆ ที่ทำได้เลยตอนนี้, และทางไปต่อถ้าอยากคุยกับใคร

## 4. การตัดสินใจออกแบบที่สำคัญ

### เลือก "ก้าวถัดไป" ตามสิ่งที่ผู้ใช้อยากได้ ไม่ใช่ตามระดับความหนัก
ข้อ 3 ถามว่า "ตอนนี้คุณอยากให้ตัวเองได้อะไรที่สุด" แล้วแสดงก้าวถัดไปตรงกับคำตอบ:

| ผู้ใช้เลือก | ก้าวถัดไป |
|---|---|
| พัก | หายใจ 1 นาที |
| ได้ระบาย | ช่องเขียนข้อความ แล้ว "วางไว้ตรงนี้" |
| จัดความคิด | ช่องเขียนเรื่องที่วนอยู่ในหัว |
| ก้าวต่อไปทีละนิด | เลือกก้าวเล็กๆ 1 อย่าง |
| แค่มีใครอยู่ข้างๆ | ลิงก์ไปคุยกับนักจิตวิทยา ooca |

**เหตุผล:** ผู้ใช้ไม่ถูกแปะป้ายว่า "หนักระดับไหน" และได้สิ่งที่ตรงกับความต้องการของตัวเอง ซึ่งน่าจะทำให้ก้าวถัดไปมีโอกาสถูกใช้จริงมากกว่า

### ไม่วินิจฉัย ใช้ภาษา "ดูเหมือนว่า…"
ข้อความทั้งหมดสะท้อนสิ่งที่ผู้ใช้ตอบ ไม่บอกว่าผู้ใช้ "เป็น" อะไร มีข้อความบอกตั้งแต่หน้าแรกว่าไม่ใช่แบบประเมินและไม่ใช่การวินิจฉัย การ์ดที่ระลึกไม่แสดงระดับความหนัก

### ความเป็นส่วนตัว: ไม่เก็บข้อมูล
ทุกอย่างทำงานบนเบราว์เซอร์ของผู้ใช้ ไม่มีฐานข้อมูล ไม่มีการส่งคำตอบไปที่ใด ข้อความที่พิมพ์ในช่อง "วางไว้ตรงนี้" จะหายไปเมื่อกดวาง (มีปุ่มให้ผู้ใช้คัดลอกไปเก็บเองได้) การ์ดที่ระลึกถูกสร้างบนเครื่องผู้ใช้

### Safety net แบบสองระดับ
- **ทุกหน้าผลลัพธ์** มีสายด่วนสุขภาพจิต **1323** (ตลอด 24 ชั่วโมง) และลิงก์ไปรู้จักบริการ ooca ในการ์ดช่วยเหลือ
- **เมื่อคะแนนรวมสูง** จะมีกล่องเตือนสีเด่นพร้อมเบอร์ 1323 และปุ่ม ooca เปลี่ยนเป็นปุ่มหลัก
- คะแนนรวม = คะแนนเริ่มต้นของสภาพอากาศ (แดดจ้า 0, เมฆ/หมอก 1, พายุ 2) + คะแนนของแต่ละคำตอบ (เต็ม 9) แสดงกล่องเตือนเมื่อ ≥ 7

**ทำไมไม่โปรโมต ooca ให้ทุกคนเท่ากัน:** ถ้าปุ่มขายบริการเด่นเท่ากันทุกคน ผู้ใช้ที่แค่อยากเช็กอินเบาๆ จะรู้สึกถูกขาย ส่วนผู้ที่หนักจริงควรเห็นทางช่วยเหลือชัดเจนที่สุด

### ให้ผู้ใช้ควบคุมได้
ข้ามได้ทุกคำถาม ย้อนกลับได้ ไม่ต้องสมัคร ไม่บังคับให้เขียนอะไร

### การ์ดที่ระลึกที่ "อยากเก็บ"
การ์ดมีสีและท่ามาสคอตต่างกันตามสภาพอากาศ มีชื่อสภาวะ ประโยคสะท้อน ข้อความกำลังใจ และวันที่ ไม่มีการแสดงระดับความหนักหรือคะแนน เพื่อให้เป็นของที่ผู้ใช้ภูมิใจเก็บ ไม่ใช่ป้ายผลวินิจฉัย

## 5. ภาพลักษณ์และ CI

ใช้สี รูปทรง และมาสคอตตาม CI ของ ooca: สี Turquoise เป็นหลัก พื้นหลัง gradient, มุมโค้ง 24px สำหรับปุ่มและการ์ด, ภาพมาสคอต (มูก้า) 5 ท่าตามสภาพอารมณ์ ฟอนต์ตาม stack Gotham Rounded → Noto Sans Thai → Tahoma

## 6. เทคโนโลยี

- **React 18 + Vite 6 + Tailwind CSS 4** (ไม่มีแบ็กเอนด์)
- ข้อความ คำถาม และกฎทั้งหมดอยู่ใน `src/data/content.js` แก้เนื้อหาได้โดยไม่ต้องแตะ component
- การ์ดที่ระลึกวาดบน canvas ในเครื่องผู้ใช้ (`src/lib/keepsake.js`)
- Deploy บน Netlify

### รันในเครื่อง
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # ได้โฟลเดอร์ dist
npm run preview  # ดูเวอร์ชันที่จะขึ้นจริง
```

### โครงสร้างโปรเจกต์
```
src/
├─ data/content.js        ข้อความ คำถาม สภาพอากาศ ลิงก์ ooca
├─ lib/
│  ├─ reflection.js       ประโยคสะท้อนใจ คะแนน safety net ข้อความกำลังใจ
│  ├─ keepsake.js         วาดการ์ดบน canvas ดาวน์โหลด แชร์
│  └─ weatherSvg.js       ไอคอนสภาพอากาศ
├─ components/            หน้าจอ: Intro, Question, Result, NextStep, SupportCard, Keepsake
├─ App.jsx                คุมลำดับขั้นตอน
└─ index.css              design token ตาม CI และคลาสที่ใช้ซ้ำ
public/mascot/            ภาพมาสคอต
```

## 7. ข้อจำกัดที่ต้องบอกตรงๆ

- **เกณฑ์คะแนน safety net เป็น heuristic ที่ออกแบบเอง** ไม่ได้ผ่านการตรวจโดยนักจิตวิทยาหรือผู้เชี่ยวชาญ ถ้านำไปใช้จริงต้องให้ทีมผู้เชี่ยวชาญของ ooca ตรวจและปรับ
- **ยังไม่ได้ทดสอบกับผู้ใช้จริง** ผู้ใช้เป้าหมายเป็นสมมติฐาน
- **ภาษาไทยในผลลัพธ์ประกอบจากวลีสำเร็จรูป** ทดสอบทุกชุดคำตอบแล้วว่าไม่มีข้อความพัง (4,320 ชุด) แต่ยังไม่ได้ให้ผู้เชี่ยวชาญด้านภาษาหรือจิตวิทยาตรวจน้ำเสียง
- **ฟอนต์ Gotham Rounded ยังไม่ได้ฝังไฟล์** บนเครื่องที่ไม่มีฟอนต์นี้ จะแสดงผลด้วยฟอนต์สำรอง หน้าตาอาจต่างกันเล็กน้อย
- **ยังไม่ได้ใช้ไอคอนจากชุด CI** ปุ่มส่วนใหญ่เป็นข้อความ
- **ทดสอบบนอุปกรณ์จริงในวงจำกัด** เคยเจอปัญหาการ์ดที่ระลึกบนมือถือที่ข้อความภาษาไทยจัดตำแหน่งเพี้ยน ซึ่งแก้แล้วด้วยการคำนวณตำแหน่งกึ่งกลางเอง ปุ่มแชร์ขึ้นอยู่กับเบราว์เซอร์และอุปกรณ์ ยังไม่ได้ทดสอบครบทุกรุ่น
- **ไม่มีระบบวัดผล** เพราะเลือกความเป็นส่วนตัวก่อน

## 8. ถ้ามีเวลาทำต่อ

1. ให้นักจิตวิทยาตรวจเกณฑ์คะแนน ข้อความ และลำดับก้าวถัดไป
2. ทดสอบกับผู้ใช้ 5–8 คนในกลุ่มวัยทำงาน ดูว่าข้อความอ่านแล้วรู้สึกอย่างไร และก้าวถัดไปตรงกับความต้องการจริงไหม
3. ถ้าจะวัดผล ใช้ตัวชี้วัดที่ไม่ระบุตัวตน เช่น อัตราจบประสบการณ์, สัดส่วนที่กดก้าวถัดไป, สัดส่วนที่บันทึกการ์ด, สัดส่วนที่ข้ามคำถาม
4. เพิ่มท่ามาสคอตให้ตรงสภาพอากาศมากขึ้น (เช่น มูก้าถือร่มตอนพายุ)
5. ฝังฟอนต์ตาม CI และใช้ไอคอนจากชุด CI
6. ตรวจความเข้าถึงเพิ่ม (screen reader, ความคมชัดสี, ขนาดปุ่ม)
7. เวอร์ชันภาษาอังกฤษ
8. เชื่อมปุ่ม ooca ไปยังหน้าจองนักจิตวิทยาโดยตรง

## 9. การใช้เครื่องมือ AI

ใช้ผู้ช่วย AI ช่วยระดมไอเดีย ร่างข้อความภาษาไทย และเขียนโค้ดบางส่วน การตัดสินใจเลือกแนวคิด การแก้ไขข้อความ การทดสอบ และการนำไปใช้จริงทำโดยผู้พัฒนา
